# データ出典と再現条件

## 道路照明灯

- 提供元：静岡県 道路保全課
- 公開ページ：https://opendata.pref.shizuoka.jp/dataset/fuji-163.html
- 元ファイル：`照明灯（20231004）.csv`
- ブログ検証時の取得日：2026-11-11
- 元ファイルのSHA-256：`d74f961a5849856c36afcbb1bedb0076f8c854c861335cdd0ae2b793426b7c62`
- 入力は日本語列名、CP932。全11,087行から「設置位置」に「下田市」を含む271行を抽出。
- 座標欠損0、管理番号欠損・重複0、照明灯種別空欄22。同一座標の別管理番号は保持。
- 出力はUTF-8 BOM付き。SOURCE_ROWはヘッダーを除く元データ行番号。

提供元の利用条件と出典表示に従ってください。加工済みCSVもこのリポジトリには含めません。

## 海岸線

- 提供元：国土地理院・基盤地図情報 https://service.gsi.go.jp/kiban/
- 基本項目 → 海岸線（Cstline）。水涯線・標高モデルではありません。
- ブログ検証時の一括ZIP：`20261113001334870-001.zip`
- 5238・5138に属する次の26個の2次メッシュ。

```text
513867,513870,513871,513876,513877,523801,523802,523805,523806,523807,523812,523815,523816,523822,523826,523832,523833,523834,523836,523843,523844,523846,523847,523854,523855,523856
```

GMLの各ファイルには作成日があり、同じ日に取得してもメッシュごとに版が異なります。同一地域の過去版と最新版を重ねないようにします。各ファイルのハッシュを変換時のmanifestに残します。COAST_IDは入力の処理順から生成されるため、元ファイルの組み合わせや版を変えると対応が変わります。

今回の入力：海岸線XML26ファイル＋メタデータXML26ファイル。Cstline出力4,991地物（海岸線4,817・その他174）。GMLは緯度・経度、GeoJSONは経度・緯度の順で記録します。

JGD2024の2D水平座標をJGD2011のEPSG:6668として処理し、pyprojでWGS84へ変換します。標高や観測時点の地殻変動の補正は含みません。参考：[日本の測地系](https://www.gsi.go.jp/sokuchikijun/datum-main.html)。

除外する13件のCOAST_IDはこの入力セットに固有です。別の入力セットへそのまま適用しないでください。SQLは件数・形状・候補状態・短線の範囲・全設備への除外影響を確認し、不一致では停止します。

### 出典表記例

出典：静岡県「道路照明灯」、国土地理院「基盤地図情報（海岸線）」を加工して作成。

地図を公開する場合は、背景地図の帰属表示（MapTiler / OpenStreetMap等）も残します。元のCSV・ZIP・変換後のGeoJSON・スクリーンショットはリポジトリには同梱しません。
